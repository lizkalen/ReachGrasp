<h1 align="center">
  Reach & Grasp
</h1>

<p align="center"><img src="https://github.com/DarioDiDomenico/Reach-Grasp/blob/main/assets/movement.gif" alt="" /></p>
This repository is associated to the dataset Reach&Grasp presented in the publication [Scientific Data](https://rdcu.be/ei71E).
This code utilizes the cbss algorithm to decode individual MUs.


The original repository is maintained by:

(https://github.com/DarioDiDomenico) [@dariodidomenico](https://github.com/DarioDiDomenico)

## How to access data

We provide [Matlab](https://github.com/DarioDiDomenico/Reach-Grasp/tree/1c675ea611cc46e4682ba93d0f1808af694f1165/code) code to access the information contained in the dataset and to generate figures contained in the Dataset article.
